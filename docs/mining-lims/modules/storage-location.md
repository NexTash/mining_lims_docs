# Storage Location

**Purpose:** the places where samples are kept: rooms, cabinets, racks, shelves. Locations
form a tree (Room → Rack → Shelf); samples are stored on the leaf locations.

**Who:** Technician and Head of Laboratory create; everyone reads.

| Field | Meaning |
| --- | --- |
| Location Name, Type | Name (Core rack A / Shelf 2) and kind (Room, Refrigerator, Freezer, Cabinet, Shelf, Rack, Other). |
| Status | Active, Maintenance or Inactive. |
| Parent Location, Is Group | Place in the tree; a group holds other locations. |
| Temperature, Capacity, Description | Conditions and size. |
