# Settings

**Mining LIMS Settings** holds the laboratory's identity and the process rules. Only the
Head of Laboratory (and System Manager) can change it.

## Laboratory

| Field | Meaning |
| --- | --- |
| Laboratory Name, Subtitle, Division | Printed in the letterhead and footer of every report, receipt and invoice. |
| Accreditation Line, Accreditation No. | Printed under the laboratory name. |
| Email, Website, Address, Phone | Contact details on the letterhead. |
| Director of Centre (printed) | Name printed under the Director's signature when the approving user's name should not be used. |

## Report text and logos

| Field | Meaning |
| --- | --- |
| Report Limitation | Disclaimer printed on every test report. |
| DRAFT watermark until released | Reports of samples that are not yet Approved show a DRAFT watermark. |
| Header Logo, Watermark Logo | Images for the letterhead and the released reports. |

## Process rules

| Field | Meaning |
| --- | --- |
| Block On Expired Calibration | Refuse equipment with expired or missing calibration on samples being prepared or tested. |
| Require Preparation Record | Show a reminder when a test that requires a preparation record is started on a specimen without one. |
| Default Customer Report | Brief or Detailed; what the customer receives unless the Head of Laboratory chooses otherwise at review. |
| Sample Retention Days | Default retention when the Test has none. |
| Calibration Reminder Days | How many days before the due date the calibration reminder is sent. |

## Documentation

| Field | Meaning |
| --- | --- |
| Documentation URL | Base address of this documentation. The **Help** menu and the **Documentation** entries point here, so the documentation can be moved without changing the software. |
