# Parameter

**Purpose:** a quantity the laboratory reports: compressive strength, moisture content,
plasticity index, point load index. Parameters are shared between tests; the unit, decimals
and uncertainty for a given test are set on the Test's parameter line.

**Who:** Head of Laboratory creates; everyone reads.

## Fields

| Field | Meaning |
| --- | --- |
| Parameter Name, Abbreviation | Name on the report; short code in tables (UCS, w, PI). |
| Status | Active or Inactive. |
| Description | Free text. |
| Result Type | Numeric, Text or Selection (one allowed value per line in **Selection Options**). |
| Decimal Places | Default precision; a Test can override it. |
| Accredited | Within the accreditation scope; marked with ^ on the Test Report. |
