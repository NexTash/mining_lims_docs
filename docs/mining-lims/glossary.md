# Glossary

| Term | Meaning |
| --- | --- |
| **Request** | The customer's order for testing: tests and sample counts. |
| **Sample** | One delivered sample or one specimen, with its status through the laboratory. |
| **Piece / child sample** | A specimen cut from a delivered sample; has its own code, label and data sheet. |
| **Specimen Code** | The laboratory's number printed on the report (UCS-0005), separate from the record ID. |
| **Observation Data Sheet (ODS)** | The electronic worksheet where readings are entered and results calculated. |
| **Test** | A service the laboratory offers; links standard, data sheet, parameters, price and report templates. |
| **Test Method** | The definition of a data sheet: fields, formulas, checks, charts. |
| **Parameter** | A reported quantity (compressive strength, moisture content). |
| **Standard** | A test method or practice the laboratory follows, or a specification with acceptance limits. |
| **Specification** | A standard of type Specification: limits that results are compared with. |
| **Validity check** | A requirement of the standard verified by the data sheet; block, flag or note. |
| **Data-logger file** | The export from a testing machine (csv, tsv, txt, xlsx) imported on the data sheet. |
| **Channel** | A quantity the method expects in a data-logger file (time, load, axial strain ...). |
| **Internal / Detailed / Brief report** | The three report templates of a test. |
| **Letterhead** | Laboratory header and footer printed on every document, from Settings. |
| **Workflow / Actions** | The statuses of a record and the actions that move it between them. |
| **Portal** | The customer's own view: requests, sample status, approved reports. |
| **Retention period** | How long tested material is kept before disposal or return. |
| **Custody log** | The list of hand-overs of a sample. |
| **MNS ISO/IEC 17025** | The Mongolian adoption of the international standard for testing laboratories. |
| **ASTM** | ASTM International, publisher of the test method standards used. |
